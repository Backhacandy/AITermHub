# AITermHub 사용 설명

## 1. 설치
1. [최신 릴리스](https://github.com/Backhacandy/AITermHub/releases/latest)에서 `AITermHub_…_x64-setup.exe`를 받아 실행해요.
2. "Windows의 PC 보호"가 뜨면 **추가 정보 → 실행**. (코드 서명 인증서가 아직 없어서 뜨는 경고예요.)
3. 내 계정에만 설치돼요(관리자 권한 필요 없음).

## 2. 처음 켜기
- Claude Code·Codex CLI가 설치돼 있는지 확인해요. 없으면 설치 명령을 복사해 터미널에서 실행한 뒤 **다시 확인**.
  - Claude Code(PowerShell): `irm https://claude.ai/install.ps1 | iex`
  - Codex: `npm install -g @openai/codex`
- Gemini·Qwen·OpenCode·Copilot·Cursor·Aider 같은 다른 AI CLI가 깔려 있으면 그것도 찾아요. 하나만 있어도 돼요.
- Claude·Codex는 이미 로그인돼 있는지 CLI에게 직접 물어 보여 줘요. 로그인은 첫 세션을 열면 각 CLI가 안내해요. AITermHub는 로그인 정보 파일을 읽거나 옮기지 않아요.

## 3. 세션 열기
- 위쪽 **＋ → 새로 만들기**에서 Claude·Codex 또는 이 PC에 있는 다른 AI를 고르고 프로젝트 폴더를 정해요. 다른 AI는 터미널 탭으로 열려요.
- 왼쪽은 대화, 오른쪽은 작업 현황(읽은 파일·바꾼 파일·실행한 명령)이에요.
- 같은 폴더의 지난 대화를 이어 가려면 **대화 ▾**에서 골라요.

## 4. 재우기와 이어 하기
- 쉬는 세션은 잠들어 메모리를 돌려줘요. 구조화 Claude 탭은 **2분**, 터미널 탭은 **15분**(설정 → 운영 방식에서 바꿀 수 있어요). **1시간** 넘게 쉬면 프로세스를 꺼요(대화는 남음).
- 잠든 세션에 다시 지시하면 같은 대화로 이어져요.
- 왼쪽 **현황**에서 세션별 상태(작업 중·유휴·수면)와 메모리를 봐요.
- 설정 → 운영 방식에서 재우기·끄기 시간을 바꿀 수 있어요.

## 5. 사용량
- 왼쪽 **사용량 · 한도**에서 5시간·주간 한도를 봐요.

## 6. 실험 기능
- 설정 → 실험 기능 → **팀 · 비교 탭**을 켜면 여러 에이전트를 나눠 맡기는 팀 탭과 Claude vs Codex 비교 탭을 만들 수 있어요.
- 실측상 단일 세션보다 느리고 토큰을 더 쓸 수 있어요.

## 7. 밖으로 연결하는 기능
설정 → 정보에 모두 적혀 있어요. 사용 통계는 보내지 않아요.
- 업데이트 확인(GitHub 릴리스) — 시작할 때와 하루 한 번
- 모바일 원격, ntfy 알림, GitHub 잔디·포트폴리오, CLI 자동 업데이트 — 설정에서 켰을 때만

## 8. 업데이트
- 새 버전이 나오면 위쪽에 알림이 떠요. **지금 설치** 또는 **일이 끝난 뒤**를 눌러야 설치돼요.

## 9. 알려진 한계
- Windows 전용이에요(Mac·Linux는 계획 중).
- 화면은 한국어만 있어요.
- 코드 서명이 없어 처음 설치할 때 경고가 떠요.
- 버그는 [이슈](https://github.com/Backhacandy/AITermHub/issues/new/choose)로 알려 주세요.
